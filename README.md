# 🌿 이끼숲 관극 다이어리

뮤지컬 〈이끼숲〉(2026.10.01 – 12.13 · 백암아트홀) 관람 기록 PWA.

**👉 [앱 열기](https://musical-otk.github.io/ikkisup2026/)** · [사용 가이드](https://musical-otk.github.io/ikkisup2026/guide.html)

기록은 **기기 안에만** 저장됩니다 (localStorage). 서버로 전송되지 않으며 기기 간 동기화도 없습니다.
백업은 설정 → JSON 내보내기를 쓰세요.

## 기능

| 화면 | 내용 |
| --- | --- |
| 🏠 홈 | 다음 공연 D-day·캐스팅·좌석, 예정 일정, 쿠폰·재관람 카드 현황 |
| 📅 캘린더 | 전체 회차, 배역별 캐스팅 필터, 특전 기간 표시(공식 안내 링크) |
| 🎫 쿠폰·도장 | 할인권 잔여 관리, 재관람 카드 8칸(4·6·8회 혜택) |
| 😌 통계 | 좌석 히트맵(1·2층), 배우별·조합별 관람, 지출 |
| ⚙️ 설정 | 다크모드, 글자 크기, 백업·복원 |

## 앱으로 설치 (PWA)

Safari / Chrome으로 접속 → 공유 → **홈 화면에 추가**.
설치하면 전체화면으로 실행되고 오프라인에서도 열립니다.

## 개발

```powershell
.\run_tests.ps1        # 3계층 검사 (데이터 / 정적 / 로직)
```

| 계층 | 도구 | 내용 |
| --- | --- | --- |
| L1 데이터 | `scripts/validate.py` | 스케줄·좌석·캐스팅 정합성 |
| L2 정적 | `scripts/check_html.py` | id 참조, 외부 링크 인벤토리 |
| L3 로직 | `selftest.html` | index.html을 iframe으로 띄워 27건 검증 |

`selftest.html`은 브라우저에서 직접 열어도 되고, headless Chrome으로도 돌아갑니다.
`_shots.html`은 가이드용 스크린샷 촬영 하네스입니다.

설계 문서는 [DESIGN.md](DESIGN.md), 검사 시나리오는 [TEST_PLAN.md](TEST_PLAN.md)를 보세요.
